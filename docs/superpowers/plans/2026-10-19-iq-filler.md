# Empower Smart IQ Filler Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static, in-browser web app at iq.mhpwebserver.com that fills the Waters Empower Servers IQ workbook (715002791) from ipconfig / msinfo32 / Empower.log / Checksum / tnsnames / Licensing Wizard files, with a review step, and downloads the filled PDF.

**Architecture:** Pure ES modules in `www/js/` — one parser per file type (text → facts), a merge step with precedence + provenance, a template module that turns facts + the PDF's current field values into review rows and stamp positions, and a pdf-lib filler. No backend; nginx serves `www/` as static files. Every module is a pure function so Node's built-in test runner imports the same files the browser does.

**Tech Stack:** Vanilla JS (ES2022 modules), pdf-lib 1.17.1 (fill/stamp), pdfjs-dist 6.2.108 (text extraction), the License Cleaner's `core.js` (license parsing, vendored), Node 24 `node:test` for tests, nginx static vhost.

**Spec:** `docs/superpowers/specs/2026-10-19-iq-filler-design.md`

## Global Constraints

- Workbook: Waters part number `715002791` (Rev E). Only this template.
- Files never leave the browser: no `fetch`/XHR of user data anywhere; no backend.
- Never fill: signatures (PDFSignature fields), `Initials`, `Initials_2`, `Date`, `Date_2`, `Date_3`, `Date_4`, `Name_2`, `Trained and qualified to perform qualification procedures2` (reviewer title).
- No inline `<script>` and no inline event handlers (site CSP `script-src 'self'`). JS in files only.
- Vendored pdf.js files are renamed `.mjs` → `.js` (nginx serves `.mjs` as octet-stream, which blocks module scripts).
- US spelling in UI copy ("license", "recognized").
- Tile colors: gold `#FDE68A` → `#CA8A04`. Product name: "Empower Smart IQ Filler".
- Repo is public-bound: **never commit real customer files or the Waters template PDF.** Fixtures use host `LABSVR01`, domain `example.com`, IPs `10.0.0.x`, company `Example Pharma`.
- Git identity in this repo: `mattpetosa <16355926+mattpetosa@users.noreply.github.com>` (already set). Commit messages end with the session attribution lines.
- Real template (local only): `/mnt/empower-backend/EmpowerSmartIQFiller/templates/Empower_3.10.0_IQ_for_Servers_715002791_RevE.pdf`.
- Deploying (nginx, CSP, empower card) and pushing to GitHub require Matt's explicit OK at that moment.

## Review Focus

1. A pre-filled template whose drive rows already hold different drives (C/D/E/F) than the server has (C/E/F/G/H) — every stale row must be overwritten or cleared, never left mixed. (Task 8 test `stale drive rows are cleared`.)
2. Checksum file without any `Option Properly Installed` lines — must not turn every option row into "No". (Task 6 test `checksum without options is not a license source`.)
3. Hostname disagreement across files (ipconfig `LABSVR01` vs Checksum `Labsvr01` must NOT warn — case only; vs MSInfo `OTHERHOST` must warn). (Task 7 tests.)
4. Same IQ PDF dropped into the system-files zone, or a Wizard PDF dropped into the IQ zone — must be redirected/rejected with a clear message, not parsed as the wrong thing. (`classifyPdfText` test in Task 3 + Task 10 browser checks.)
5. msinfo32 `.txt` export (no real sample yet) — parser must still yield drives/hardware from the documented layout and must not crash on unknown sections. (Task 4 test on the `.txt` fixture.)

`www/js/pdfform.js` (initial):
```js
// pdf-lib is passed in (PDFLib namespace) so the same module runs in the
// browser (vendor/pdf-lib.esm.min.js) and in Node tests (npm 'pdf-lib').

/** Read every AcroForm field: name, kind, 1-based page, rect, current value. */
export async function readPdfFields(PDFLib, bytes) {
  const doc = await PDFLib.PDFDocument.load(bytes);
  const pageOf = new Map();
  doc.getPages().forEach((page, i) => {
    const annots = page.node.Annots();
    if (!annots) return;
    for (let k = 0; k < annots.size(); k++) pageOf.set(String(annots.get(k)), i + 1);
  });
  const fields = [];
  for (const f of doc.getForm().getFields()) {
    const widget = f.acroField.getWidgets()[0];
    const ref = widget ? doc.context.getObjectRef(widget.dict) : undefined;
    const r = widget ? widget.getRectangle() : { x: 0, y: 0, width: 0, height: 0 };
    const isText = f instanceof PDFLib.PDFTextField;
    fields.push({
      name: f.getName(),
      type: isText ? 'text' : 'other',
      page: ref ? (pageOf.get(String(ref)) ?? null) : null,
      rect: [r.x, r.y, r.width, r.height],
      value: isText ? (f.getText() ?? '') : '',
      multiline: isText ? f.isMultiline() : false,
    });
  }
  return { doc, fields };
}
```

```js
/** A synthetic stand-in for the Waters template: same field names, pages and rects. */
export async function makeTemplate(PDFLib, { values = {}, partNumber = '715002791' } = {}) {
  const { PDFDocument, StandardFonts } = PDFLib;
  const doc = await PDFDocument.create();
  const font = await doc.embedFont(StandardFonts.Helvetica);
  for (let i = 0; i < 16; i++) doc.addPage([612, 792]);
  doc.getPage(0).drawText(`Workbook Part Number: ${partNumber} Revision E`, { x: 72, y: 600, size: 12, font });
  const form = doc.getForm();
  for (const f of FIELDS) {
    if (f.type !== 'text') continue;
    const tf = form.createTextField(f.name);
    if (f.multiline) tf.enableMultiline();
    tf.addToPage(doc.getPage(f.page - 1), { x: f.rect[0], y: f.rect[1], width: f.rect[2], height: f.rect[3], font });
    if (values[f.name] != null) tf.setText(values[f.name]);
  }
  return doc.save();
```

- [ ] **Step 3: Implement fillPdf**

Append to `www/js/pdfform.js`:
```js
/**
 * Write `values` into the matching text fields and draw `stamps` into page
 * content. Only written fields get a regenerated appearance: untouched fields
 * keep the look the template author's PDF editor gave them. The Waters
 * template's fields carry no /DA, which pdf-lib needs before it can size text,
 * so one is added to each field we write.
 */
export async function fillPdf(PDFLib, bytes, values, stamps) {
  const { PDFDocument, StandardFonts, PDFName, PDFTextField } = PDFLib;
  const doc = await PDFDocument.load(bytes);
  const form = doc.getForm();
  const font = await doc.embedFont(StandardFonts.Helvetica);
  const byName = new Map(form.getFields().map(f => [f.getName(), f]));
  for (const [name, value] of Object.entries(values)) {
    const f = byName.get(name);
    if (!(f instanceof PDFTextField)) continue;
    f.setText(value ?? '');
    if (!f.acroField.getDefaultAppearance()) f.acroField.setDefaultAppearance('/Helv 0 Tf 0 g');
    f.setFontSize(10);
    f.defaultUpdateAppearances(font);
  }
  form.acroForm.dict.delete(PDFName.of('NeedAppearances'));
  for (const s of stamps) doc.getPage(s.page - 1).drawText(s.text, { x: s.x, y: s.y, size: 9, font });
  return doc.save({ updateFieldAppearances: false });
}
```

```js
/** Bytes → text. msinfo32 .nfo files are UTF-16LE with a BOM. */
export function decodeText(bytes) {
  if (bytes[0] === 0xff && bytes[1] === 0xfe) return new TextDecoder('utf-16le').decode(bytes.subarray(2));
  if (bytes[0] === 0xfe && bytes[1] === 0xff) return new TextDecoder('utf-16be').decode(bytes.subarray(2));
  const start = bytes[0] === 0xef && bytes[1] === 0xbb && bytes[2] === 0xbf ? 3 : 0;
  return new TextDecoder('utf-8').decode(bytes.subarray(start));
}

export function isPdf(bytes) {
  const head = new TextDecoder('latin1').decode(bytes.subarray(0, 1024));
  return head.includes('%PDF-');
}

/** Which parser understands this text, judged by content (never by filename). */
export function detectText(text) {
  if (text.includes('<MsInfo>') || /System Information report written at/.test(text)) return 'msinfo';
  if (text.includes('Windows IP Configuration')) return 'ipconfig';
  if (/Waters File Verification|Waters Installation Qualification - Summary|Option Properly Installed/.test(text)) return 'checksum';
  if (/Empower Deployment Manager|\*{3,} Machine Name:/.test(text)) return 'empowerlog';
  if (/\(\s*DESCRIPTION\s*=/i.test(text) && /HOST\s*=/i.test(text)) return 'tnsnames';
  return null;
}

/** A dropped PDF is either the IQ workbook or a Licensing Wizard printout. */
export function classifyPdfText(text, partNumber) {
  if (text.includes(partNumber)) return 'iq';
  if (text.includes('Serial No:')) return 'wizard';
```

```js
// `ipconfig /all` output. Keys use dot leaders ("Host Name . . . : X");
// multi-valued keys (DNS servers, gateway, suffix list) continue on lines
// that are only deep indentation + a value.
const KV = /^\s+(\S.*?)(?:\s*\.)+\s*:\s?(.*?)\s*$/;
const CONT = /^\s{10,}(\S.*?)\s*$/;
const IPV4 = /^\d{1,3}(?:\.\d{1,3}){3}$/;

export function parseIpconfig(text) {
  const sections = [{ name: 'global', kv: new Map() }];
  let lastKey = null;
  for (const line of text.split(/\r\n|\r|\n/)) {
    if (!line.trim()) continue;
    if (/^\S/.test(line)) {                       // section header
      // The banner opens the global section (Host Name, Primary Dns Suffix).
      if (/^Windows IP Configuration/i.test(line)) { lastKey = null; continue; }
      sections.push({ name: line.replace(/:\s*$/, '').trim(), kv: new Map() });
      lastKey = null;
      continue;
    }
    const sec = sections[sections.length - 1];
    const m = KV.exec(line);
    if (m) {
      lastKey = m[1].trim();
      sec.kv.set(lastKey, m[2] ? [m[2].trim()] : []);
      continue;
    }
    const c = CONT.exec(line);
    if (c && lastKey) sec.kv.get(lastKey).push(c[1]);
  }
  const first = (sec, ...keys) => { for (const k of keys) { const v = sec.kv.get(k)?.find(Boolean); if (v) return v; } return undefined; };
  const strip = v => v?.replace(/\(.*\)$/, '').trim();
  const global = sections[0];
  const adapters = sections.slice(1).filter(s => / adapter /i.test(s.name) && first(s, 'IPv4 Address', 'IP Address'));
  const warnings = [];
  const facts = {};
  const host = first(global, 'Host Name');
  if (host) facts.hostname = host;
  const a = adapters[0];
  const domain = first(global, 'Primary Dns Suffix') || (a && first(a, 'Connection-specific DNS Suffix'));
  if (domain) facts.domain = domain;
  if (a) {
    facts.ipv4 = strip(first(a, 'IPv4 Address', 'IP Address'));
    const subnet = first(a, 'Subnet Mask'); if (subnet) facts.subnet = subnet;
    const gw = (a.kv.get('Default Gateway') || []).map(strip).find(v => IPV4.test(v)); if (gw) facts.gateway = gw;
    const dns = (a.kv.get('DNS Servers') || []).map(strip).filter(Boolean); if (dns.length) facts.dns = dns;
    const nic = first(a, 'Description'); if (nic) facts.nic = nic;
    for (const other of adapters.slice(1)) warnings.push(`ipconfig: also found ${other.name} (${strip(first(other, 'IPv4 Address', 'IP Address'))}); using ${a.name}.`);
  } else {
    warnings.push('ipconfig: no adapter with an IPv4 address.');
  }
  return { kind: 'ipconfig', facts, warnings };
}
```

```js
// msinfo32 export: .nfo (XML; nested <Category name=...>, rows are
// <Data><Item/><Value/></Data>) or .txt ([Section] headers, Item<TAB>Value rows).
// Both are reduced to Map<sectionName, [item, value][]>.
const VIRTUAL = /vmware|virtual machine|virtualbox|innotek|qemu|kvm|xen|parallels|amazon ec2|google compute/i;

function nfoSections(text) {
  const sections = new Map(), stack = [];
  const re = /<Category name="([^"]*)">|<\/Category>|<Data>\s*<Item><!\[CDATA\[([\s\S]*?)\]\]><\/Item>\s*<Value><!\[CDATA\[([\s\S]*?)\]\]><\/Value>\s*<\/Data>/g;
  for (const m of text.matchAll(re)) {
    if (m[1] !== undefined) { stack.push(m[1]); if (!sections.has(m[1])) sections.set(m[1], []); }
    else if (m[0] === '</Category>') stack.pop();
    else if (stack.length) sections.get(stack[stack.length - 1]).push([m[2], m[3]]);
  }
  return sections;
}

function txtSections(text) {
  const sections = new Map();
  let cur = null;
  for (const line of text.split(/\r\n|\r|\n/)) {
    const h = /^\[(.+)\]\s*$/.exec(line);
    if (h) { cur = []; sections.set(h[1], cur); continue; }
    if (!cur || !line.includes('\t')) continue;
    const [item, value = ''] = line.split('\t');
    if (item === 'Item' && value === 'Value') continue;
    cur.push([item, value]);
  }
  return sections;
}

function sizeGB(s) {
  const m = /([\d.,]+)\s*(TB|GB|MB)/i.exec(s || '');
  if (!m) return null;
  const n = parseFloat(m[1].replace(/,/g, ''));
  const unit = m[2].toUpperCase();
  return Math.round(unit === 'TB' ? n * 1024 : unit === 'MB' ? n / 1024 : n);
}

function processorText(lines) {
  if (!lines.length) return undefined;
  const name = lines[0].split(',')[0].trim();
  const cores = /(\d+)\s*Core\(s\)/i.exec(lines[0])?.[1];
  if (lines.length > 1) return `${lines.length} x ${name}${cores ? ` (${cores} cores each)` : ''}`;
  return `${name}${cores ? ` (${cores} cores)` : ''}`;
}

export function parseMsinfo(text) {
  const sections = text.includes('<MsInfo>') ? nfoSections(text) : txtSections(text);
  const summary = sections.get('System Summary') || [];
  const one = item => summary.find(([k]) => k === item)?.[1]?.trim() || undefined;
  const facts = {};
  const set = (k, v) => { if (v) facts[k] = v; };
  set('hostname', one('System Name'));
  set('os', one('OS Name'));
  set('manufacturer', one('System Manufacturer'));
  set('model', one('System Model'));
  set('systemType', one('System Type'));
  set('processor', processorText(summary.filter(([k]) => k === 'Processor').map(([, v]) => v)));
  const ram = one('Installed Physical Memory (RAM)');
  if (ram) set('ram', ram.replace(/(\d+)\.0+\s*/, '$1 '));
  if (facts.manufacturer || facts.model) facts.virtual = VIRTUAL.test(`${facts.manufacturer || ''} ${facts.model || ''}`);

  const drives = [];
  let d = null;
  for (const [item, value] of sections.get('Drives') || []) {
    if (item === 'Drive') { d = { letter: value.trim(), description: '', size: '', label: '' }; drives.push(d); continue; }
    if (!d) continue;
    if (item === 'Description') d.description = value.trim();
    else if (item === 'Size') d.size = value;
    else if (item === 'Volume Name') d.label = value.trim();
  }
  const fixed = drives
    .filter(x => /fixed/i.test(x.description) && sizeGB(x.size) !== null)
    .map(x => ({ letter: x.letter, sizeGB: sizeGB(x.size), label: x.label }))
    .sort((a, b) => a.letter.localeCompare(b.letter));
  if (fixed.length) facts.drives = fixed;

  const warnings = Object.keys(facts).length ? [] : ['MSInfo: no System Summary or Drives section found.'];
  return { kind: 'msinfo', facts, warnings };
}
```

```js
// tnsnames.ora: the net service name is the entry alias ("WAT19 = (DESCRIPTION ...").
export function parseTnsnames(text, hostname) {
  const clean = text.split(/\r\n|\r|\n/).filter(l => !/^\s*#/.test(l)).join('\n');
  const entries = [];
  const re = /^([A-Za-z][\w.\-]*)\s*=\s*\(/gm;
  const starts = [...clean.matchAll(re)];
  starts.forEach((m, i) => {
    const body = clean.slice(m.index, starts[i + 1]?.index ?? clean.length);
    const host = /HOST\s*=\s*([^)\s]+)/i.exec(body)?.[1];
    entries.push({ alias: m[1], host });
  });
  const short = h => (h || '').split('.')[0].toUpperCase();
  const mine = hostname ? entries.find(e => short(e.host) === short(hostname)) : undefined;
  const pick = mine || entries[0];
  const warnings = entries.filter(e => e !== pick).map(e => `tnsnames: also has ${e.alias} (HOST ${e.host}); using ${pick.alias}.`);
  const facts = {};
  if (pick) { facts.netServiceName = pick.alias; if (pick.host) facts.tnsHost = pick.host; }
  else warnings.push('tnsnames: no entries found.');
  return { kind: 'tnsnames', facts, warnings };
}
```

```js
// License options for Form 7, from the License Cleaner's parser (vendored
// core.js, loaded as globalThis.ESLC). First matching rule wins, so
// "Software SQT" is never also counted as "SystemsQT for systems".
const RULES = [
  ['agilentGc', /agilent\s+gc/i],
  ['agilentLc', /agilent\s+lc/i],
  ['suitability', /system\s+suitability/i],
  ['sqtSoftware', /software\s+sqt|(?:systemsqt|sqt)\s+for\s+software/i],
  ['sqtSystems', /systemsqt/i],
  ['edm2', /enterprise\s+data\s+manager|\bedm\b/i],
];

export function summarizeLicenses(res, origin) {
  const options = { base: false, agilentGc: false, agilentLc: false, suitability: false, sqtSoftware: false, sqtSystems: false, edm2: false };
  const others = [];
  for (const l of res.licenses) {
    if (l.category === 'Base License') { options.base = true; continue; }
    const hit = RULES.find(([, rx]) => rx.test(l.name));
    if (hit) { options[hit[0]] = true; continue; }
    if (l.category === 'Options' && !others.includes(l.name)) others.push(l.name);
  }
  return { origin, count: res.licenses.length, options, others };
}

export function parseWizard(text) {
  const res = globalThis.ESLC.parseWizardText(text);
  if (!res.licenses.length) return { kind: 'wizard', facts: {}, warnings: ['Licensing Wizard PDF: no license lines found.'] };
  return { kind: 'wizard', facts: { licenses: summarizeLicenses(res, 'wizard') }, warnings: [] };
}

export function licensesFromChecksum(text) {
  const res = globalThis.ESLC.parseChecksumText(text);
  return res.licenses.length ? summarizeLicenses(res, 'checksum') : null;
}
```

```js
export const SOURCE_LABEL = {
  ipconfig: 'ipconfig', msinfo: 'MSInfo', empowerlog: 'Empower.log', checksum: 'Checksum',
  tnsnames: 'tnsnames', wizard: 'Licenses', pdf: 'your PDF', typed: 'typed',
};

// Which parser kinds may supply each fact, best first.
const PRECEDENCE = {
  hostname: ['ipconfig', 'msinfo', 'empowerlog', 'checksum'],
  domain: ['ipconfig'], ipv4: ['ipconfig'], subnet: ['ipconfig'], gateway: ['ipconfig'], dns: ['ipconfig'],
  os: ['msinfo', 'empowerlog', 'checksum'],
  manufacturer: ['msinfo'], model: ['msinfo'], systemType: ['msinfo'], drives: ['msinfo'],
  processor: ['msinfo', 'empowerlog'], ram: ['msinfo', 'empowerlog'],
  virtual: ['msinfo', 'ipconfig'],
  installDate: ['empowerlog'],
  empowerVersion: ['checksum', 'empowerlog'],
  installType: ['checksum'],
  verify: ['checksum'],
  netServiceName: ['tnsnames'],
  licenses: ['wizard', 'checksum'],
};
const VIRTUAL_NIC = /vmxnet|hyper-v|virtio|xen|virtual/i;
const same = (a, b) => JSON.stringify(a).toLowerCase() === JSON.stringify(b).toLowerCase();
const shortHost = h => String(h).split('.')[0].toUpperCase();

export function mergeFacts(results) {
  const warnings = results.flatMap(r => r.warnings || []);
  const derived = results.map(r => {
    if (r.kind === 'ipconfig' && r.facts.nic && !('virtual' in r.facts) && VIRTUAL_NIC.test(r.facts.nic)) return { ...r, facts: { ...r.facts, virtual: true } };
    return r;
  });
  const facts = {};
  for (const [key, kinds] of Object.entries(PRECEDENCE)) {
    const cands = [];
    for (const kind of kinds) for (const r of derived) if (r.kind === kind && r.facts[key] !== undefined) cands.push({ value: r.facts[key], source: kind });
    if (!cands.length) continue;
    const [win, ...rest] = cands;
    const alternatives = [];
    for (const c of rest) {
      const dup = key === 'hostname' ? shortHost(c.value) === shortHost(win.value) : same(c.value, win.value);
      if (!dup && !alternatives.some(a => same(a.value, c.value))) alternatives.push(c);
    }
    facts[key] = { value: win.value, source: win.source, alternatives };
  }
  if (facts.hostname?.alternatives.length) {
    const all = [facts.hostname, ...facts.hostname.alternatives].map(c => `${SOURCE_LABEL[c.source]}: ${c.value}`).join(', ');
    warnings.unshift(`The files name different servers (${all}). Check you uploaded files from one server.`);
  }
  return { facts, warnings };
}
```

```js
function proposals(facts, pdfValue) {
  const p = {};
```

```js
import { parseText } from './parsers/index.js';
import { parseWizard } from './parsers/licenses.js';
import { mergeFacts } from './facts.js';
import { TEMPLATE } from './templates/servers-715002791.js';

/** System-file texts + Wizard PDF texts → review rows. Same path in browser and tests. */
export function buildFromInputs({ fields, texts = [], wizardTexts = [] }) {
  // Parse once without a hostname to learn it, then again so tnsnames can match it.
  const first = texts.map(t => parseText(t));
  const host = mergeFacts(first.filter(Boolean)).facts.hostname?.value;
  const results = texts.map(t => parseText(t, { hostname: host }));
  const wizards = wizardTexts.map(t => parseWizard(t));
  const ok = [...results, ...wizards].filter(Boolean);
  const merged = mergeFacts(ok);
  const { rows, warnings } = TEMPLATE.buildRows(merged, fields);
  return { rows, warnings, sources: [...results, ...wizards].map(r => ({ kind: r ? r.kind : null })) };
}

/** Apply review edits; return what fillPdf needs. */
export function finalize(rows, edits = {}) {
  const final = rows.map(r => (r.field in edits ? { ...r, value: edits[r.field] } : r));
  const all = Object.fromEntries(final.map(r => [r.field, r.value]));
  return { values: TEMPLATE.writableValues(final), stamps: TEMPLATE.stampsFor(all) };
}
```

```js
// pdf.js text extraction (browser only). Lines are rebuilt with the License
// Cleaner's itemsToLines so Wizard PDFs read exactly as ESLC reads them.
let lib;
async function pdfjs() {
  if (!lib) {
    lib = await import('../vendor/pdfjs/pdf.min.js');
    lib.GlobalWorkerOptions.workerSrc = new URL('../vendor/pdfjs/pdf.worker.min.js', import.meta.url).href;
  }
  return lib;
}

export async function pdfText(bytes, maxPages = Infinity) {
  const { getDocument } = await pdfjs();
  const doc = await getDocument({ data: bytes.slice(), isEvalSupported: false }).promise;
  const lines = [];
  try {
    for (let p = 1; p <= Math.min(doc.numPages, maxPages); p++) {
      const page = await doc.getPage(p);
      lines.push(...globalThis.ESLC.itemsToLines((await page.getTextContent()).items));
    }
  } finally { await doc.destroy(); }
  return lines.join('\n');
}
```

```js
async function loadIq(file) {
  const bytes = new Uint8Array(await file.arrayBuffer());
  if (!isPdf(bytes)) throw new Error(`${file.name} is not a PDF.`);
  const text = await pdfText(bytes, 2);
  if (classifyPdfText(text, TEMPLATE.partNumber) === 'wizard') throw new Error(`${file.name} is a Licensing Wizard printout — drop it in step 2.`);
  const { fields } = await readPdfFields(PDFLib, bytes);
  const problem = TEMPLATE.validate(text, fields);
  if (problem) throw new Error(problem);
  state.iq = { name: file.name, bytes, fields };
  state.edits = {};
  $('iq-status').textContent = `✓ ${file.name} — ${TEMPLATE.title}`;

  $('iq-status').hidden = false;
}

async function addSource(file) {
  const bytes = new Uint8Array(await file.arrayBuffer());
  if (isPdf(bytes)) {
    const text = await pdfText(bytes);
    const kind = classifyPdfText(text, TEMPLATE.partNumber);
    if (kind === 'iq') {
      if (!state.iq) return loadIq(file);
      throw new Error(`${file.name} is an IQ workbook — it belongs in step 1.`);
    }
    state.sources.push({ name: file.name, pdf: true, text, kind: kind === 'wizard' ? 'wizard' : null });
    return;
  }
  state.sources.push({ name: file.name, pdf: false, text: decodeText(bytes), kind: undefined });
}

function recompute() {
  if (!state.iq) { $('review').hidden = true; return; }

  const wizards = state.sources.filter(s => s.pdf && s.kind === 'wizard');
  const { rows, warnings, sources } = buildFromInputs({ fields: state.iq.fields, texts: texts.map(s => s.text), wizardTexts: wizards.map(s => s.text) });
  [...texts, ...wizards].forEach((s, i) => { s.kind = sources[i].kind; });
  state.rows = rows;

  renderWarnings(warnings);
  renderRows();
  $('review').hidden = false;
}

  const out = [];
  for (const [title, rows] of groups) {

      const id = `f-${btoa(unescape(encodeURIComponent(r.field))).replace(/=/g, '')}`;

      const long = /^Comments|List other activated/.test(r.field);
      const input = document.createElement(long ? 'textarea' : 'input');
      input.id = id; input.value = value;
      input.addEventListener('input', () => { state.edits[r.field] = input.value; row.classList.remove('changed'); src.replaceWith(src = chip('typed')); });
      let src = chip(edited ? 'typed' : r.source);
```
